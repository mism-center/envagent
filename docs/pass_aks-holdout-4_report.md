## Findings by weight

**Harness bugs (4, all mechanical, all fixed in rev 4.11):**

- **H17 — a container that dies with no output leaves no evidence (c302).** The L3 row had `exit None`, empty
  stderr; the agent could not classify and escalated. `wait_terminated` now returns `ENVBUILD_EXIT: container
  exited N (reason)` beside the code, and the verifier substitutes that line when the log is empty. An OOMKilled 137
  is then a classifiable row.
- **H18 — R `install.packages()` exits 0 when a package fails to install (epidemics).** `ADD_PKG testthat` rebuilt an
  image without testthat and the loop forbade the repeat. The R install step now checks `installed.packages()` and
  fails the build naming the missing packages (`ENVBUILD_R_NOT_INSTALLED`).
- **H12c — pytest re-inserts the source tree (viva-biofilm, starsim).** Installed-mode `pytest` runs with
  `--import-mode=importlib -p no:cacheprovider --basetemp=<output_path>/.pytest_tmp`.
- **H19 — a malformed command crashed `init` (catalyst-jl).** `quote_cmd` falls back to whitespace splitting on an
  unbalanced quote; `is_command` rejects such lines as examples.

**Rule-table (1, fixed):** **R2** `tellurium` 2.2.13 imports `tesbml`, which no index provides; cpm and
biosimulators_tellurium spent seven attempts over three passes on ADD/REMOVE `tesbml`. Now `UPSTREAM_BROKEN_IMPORT`
→ `PIN_PKG tellurium<2.2.11` (one corpus-sourced entry; the table is not broadened speculatively).

**Design items (7 models, unchanged):** M1 VCS install (mgen, membrane-actin); M2 compiled C++ binary (covid-sim —
now that the entry is real); M3 Node (artistoo); M5 conda names (covid19model); M6 R compile budget (epimodel);
M7 egress (physicell). **Budget (1):** viva-munk.

## Policy, restated

Two verifications in pass 3 were of an agent-chosen alternate example; pass 4 shows one was mis-attributed and the
other depends on install mode. Recommendation unchanged: a per-model ground-truth field `alternate_example_ok`, and
the scorer should report headline-example verifications separately from alternate-example ones. Until then, quote
**4/19** as the hold-out rate.
